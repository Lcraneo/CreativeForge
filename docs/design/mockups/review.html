CREATIVEFORGE STUDIO · DESIGN REVIEW

Forge UI 2.0 曜石弧光

面向「AI 资产生产控制台」的全面视觉升级：建立统一的 Design Tokens、组件规格与交互反馈体系。 本页为高保真设计稿，所有色值 / 字号 / 间距 / 圆角均与 《02 视觉规范》 一一对应，可直接用于评审与实施验收。

色彩与品牌 P1

曜石蓝黑底 + 弧光青主色 + 余烬橙强调；PReCon 青 / FAlign 紫 / GImport 翠 建立技术三原色。

精致度 P2

4 级表面 + 顶部内高光 + 1px 冷色描边；圆角/字距/描边全量 token 化，取代硬编码工具类。

排版层级 P3

11 级字号阶梯；正文 14/22，标题 600 字重，数据 tabular-nums；中英主副标规范。

布局与响应式 P4

统一 Shell：侧栏 240 + 顶栏 56 + 内容 1440；4 档断点，平板图标栏 / 手机底部 Tab。

交互反馈 P5

120/180/280ms 动效三档；hover / focus / active / loading / disabled 全状态；键盘焦点环。

可访问性 P6

正文对比度 ≥4.5:1；状态 = 颜色+图标+文案；aria-live 事件流；支持 reduced-motion。
