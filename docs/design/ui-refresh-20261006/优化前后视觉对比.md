# UI 系统性优化 · 优化前后视觉对比

> 日期：2026-10-06　范围：`studio/frontend`（CreativeForge Studio 唯一正式前端，8600）
> 方法：六项设计技能（frontend-design / impeccable / make-interfaces-feel-better / taste-skill / ui-ux-pro-max / web-interface-guidelines）融合审计 → 逐项修复 → 同位复截。
> 基调：**Warm Paper 暖纸编辑风为既定品牌世界，本轮做"精修（refinement）"而非"换风格（redesign）"**——保留纸/墨/宋体/发丝线的品牌资产，专攻质感细节、空态 Composition、交互手感与可访问性地板。

## 0. 设计读法（六技能融合结论）

- **模式判定**（impeccable）：本产品是 Operate（工具型工作台），可扫读性 > 表现欲；品牌活在精准的细节里。同时整站带 Persuade 门面（工作台英雄区），故"一处大胆、余处克制"。
- **Redesign-Preserve 纪律**（taste-skill §11）：品牌色板（纸白/墨黑/ember 金）为既定资产，不推倒；执行层反 AI 味 tells（transition-all、无意义动效、死空态、布局属性动画）。
- **质量地板**（craft-floor / web-interface-guidelines）：对比度、命中区、焦点环、冗余状态线索、骨架屏同构、`prefers-reduced-motion` 全量覆盖。
- **动效纪律**（make-interfaces-feel-better）：只动 transform/opacity；transition 禁 all；按压 0.96；高频交互零动效。

### 2.0 第二轮·技能调用轮（2026-10-06 晚，响应"可见性"反馈）

第一轮偏手感与状态层，为回应"肉眼可见"诉求，第二轮把 6 个技能**正式安装为项目级技能**（`.zcode/skills/`，全在 E 盘）并**实际调用其工具链**后落地两处显性改动：

- **工作台 · 四大工区旅程导航条**（01-workspace）：案头之下新增壹·创作 → 贰·资产库 → 叁·舞台 → 肆·手记 四格发丝线导航条——宋体 900 金色章序 + 区块名 + 旅程副题（文案直接取自 `lib/navigation.ts`，与侧栏同源零漂移），悬停底色加深 + 箭头右移，点击直达各区块首站。这把"四大功能区块的空间分配与视觉权重/视觉引导性"（原始需求原话）在首页显性落地。导航条不参与入场 stagger（导航即时呈现）。
- **历史记录页 · 档案缩略图列**（11-history）：生产档案表格新增 40px 作品缩略图列（SafeImage + CharacterArt 像素人回退，与智能体页同源），纯文字表格变成"每件作品都有档案"的视觉档案库——该页此前两轮都未触及，是用户实际驻留页面的直接改善。
- **技术中心 · 渐变文字修复**：impeccable 引擎 `detect` 机械检测器全量扫描唯一命中项（AI 味反模式 gradient-text），渐变裁字改为实色 ember 大字（强调靠字重与色彩，不靠渐变）。复扫结果 `[]` 清零。

### 2.1 壹·创作 — 工作台（01-workspace）

- **前**：整体已具规模；但灵感签悬停会带动"全部属性"过渡（含布局属性），KPI 卡投影单层，视觉分量偏飘。
- **后**：
  - 灵感签改为只过渡 `color/border-color/box-shadow/transform`，回正更利落，并新增按压 `scale(0.97)` 反馈——纸签被"按"了一下。
  - 阅读卡（工坊读数）投影升级为双层柔影：贴地环境影 + 远抛直接影，卡片"落在纸上"而非"浮在纸上"。
  - 布局结构（8/4 英雄区 + 四联读数 + 三匠分栏）保持不变——该布局信息层级正确，不做无谓重构。

### 2.2 壹·创作 — 智能体指挥中心（02-agents）

- **前**：行悬停与箭头微移已有；整体合格。
- **后**：行悬停、箭头 `translate-x` 引导保持；按钮/图标钮获得统一按压缩放与属性级过渡；骨架屏体系（全站共享）与最终内容同构。变化克制——此页原本就在地板之上。

### 2.3 贰·资产库 — 资产检查（03-asset）

- **前**：三卡（Identity / Pixel / Static）信息密度合理；但资产图为"朱印档案"回退时，真图场景无轮廓约束，图片与纸面交界含糊。
- **后**：`SafeImage` 全站追加 `1px 纯黑 10% 内缩描边`（亮色环境防"脏边"规范色），真图轮廓稳定；调色板色票、KV 行不动。破图回退仍是朱印字——品牌细节保留。

### 2.4 贰·资产库 — 设计三视图（04-design）

- **前**：正/侧/背三卡 `transition-all`，切换姿态时浏览器重算全部属性。
- **后**：过渡收敛到 `border-color/background/box-shadow`；选中态 tint + 描边语义不变，切换更"跟手"。

### 2.5 叁·舞台 — 试玩舞台（05-playtest）★ 本轮最大改进

- **前**：未选人物时，试玩区是一整块空画布，仅画布中央一行 `← 先在下方选择一个试玩人物`（Konva 文本）；右侧动作画廊同样一行灰字 + 大留白。违背"空态是行动邀请"原则，信息传达效率四区块中最弱。
- **后**：
  - 试玩区空态：画布之上覆盖纸雾层（92% 纸色 + 轻模糊），居中呈现品牌空态组件——斜纹"未凿"图标章（播放图标 + ember 菱形角标）+ 标题《选一位试玩人物》+ 两行说明 + **墨色主按钮「打开人物挑选」**。死画布变成带下一步动作的邀请函。
  - 动作画廊空态：新增居中《动作画廊待命》空态，说明"选人后这里会出现动作卡"，不再留白板。
  - 人物挑选加载态：从一行"读取近期生成记录…"改为**与最终网格同构的骨架屏**（2/4/6 列自适应，150px 卡位），加载完成零跳版。
  - 空记录态：给出《去工作台生成》主按钮——空态永不死路（no dead ends）。

### 2.6 叁·舞台 — 发布展示间（06-showcase）

- **前**：角色列表加载为纯文字占位；空记录为一行灰字。
- **后**：加载态改为与列表同构的骨架行（图块 + 双行文本条）；空记录态升级为 EmptyState + 《去工作台生成》出口；列表选择过渡属性化。

### 2.7 叁·舞台 / 壹·创作 — 批量生产线（09-batch）

- **前**：工位卡选择态 `transition-all`。
- **后**：收敛为 `border-color/box-shadow`，选中描边 + 影随状态出现，其余属性不再被动参与动画。

### 2.8 肆·手记 — 基准中心（07-benchmark）

- **前**：五张评分卡达标；ScoreBar 初次揭示用 width 动画（布局属性，逐帧 reflow）。
- **后**：ScoreBar 改 `scaleX` + `origin-left`（transform 合成器通道），同一条 600ms 标准缓动揭示，滚动/低电量设备上不再掉帧；阈值刻度线、领域渐变填充不变。视觉语法与本页 ScoreRing（ink→ember 渐变环）保持一致。

### 2.9 移动端（10-mobile-workspace，390×844）

- **前**：底部标签栏激活态只有颜色变化（违反"不得仅用颜色传达状态"）；顶栏/底栏色值硬编码在组件里。
- **后**：
  - 激活标签新增**顶部墨色短条指示器**（淡入淡出 120ms）——红绿色盲用户也能定位当前页。
  - 顶栏/底栏统一 `bg-canvas/85·95 + backdrop-blur`（色彩令牌派生，不再硬编码 rgba）。
  - 输入类控件在粗指针环境强制 ≥16px，iOS 聚焦不再触发整页缩放；全局 `touch-action: manipulation` 禁双击缩放、点按高亮与纸面同色。

## 3. 不变量（本轮刻意不动的部分）

- 品牌世界：纸白 `#f5f3ef` / 墨黑 `#1a1814` / ember 金渐变、宋体 900 展示标题、发丝线分隔、朱印与和纸胶带细节——**全部保留**。这是既定品牌资产（见 `docs/design/02-visual-spec.md`），六技能均裁定"既定世界优先于个人口味"。
- 信息架构：四大区块（壹创作/贰资产库/叁舞台/肆手记）旅程式分组、导航结构、路由与页面骨架不变。
- 组件 API：`ui.tsx` 对外接口零破坏，页面无需适配。
