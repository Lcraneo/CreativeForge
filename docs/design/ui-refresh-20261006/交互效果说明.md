# UI 系统性优化 · 交互效果说明

> 日期：2026-10-06　范围：`studio/frontend`
> 令牌单一事实来源：`src/index.css` `@theme` 块；framer-motion 侧同源常量在 `src/lib/motion.ts`。
> 本轮交互优化遵循三条铁律：
> 1. **只动合成器属性**——动画/过渡只允许 `transform`、`opacity`（及其 SVG 等价物、filter），禁止 `width/left/top` 等布局属性。
> 2. **transition 禁 all**——每个过渡显式列出会变化的属性，浏览器不必为无关属性建过渡轨道。
> 3. **动效必须有动机**——反馈用户操作、指示状态变化、引导层级；高频交互（悬停行、输入）不加编排动效，且每个动效状态都有静态冗余线索（色、形、字重）。

## 1. 动效令牌（全局统一）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--ease-standard` | `cubic-bezier(0.2, 0.8, 0.2, 1)` | 全站唯一标准缓动（快出缓停） |
| `--motion-fast` | 120ms | 悬停/按压/焦点等微交互 |
| `--motion-base` | 180ms | 开合、Switch 滑块 |
| `--motion-deliberate` | 280ms | 路由进入过渡 |
| `--motion-reveal` | 600ms | ScoreBar/ScoreRing 数据揭示 |
| `MOTION / EASE_STANDARD`（TS） | 同上同值 | framer-motion 组件内引用，禁止裸写时长 |

`prefers-reduced-motion: reduce` 时，全站 CSS 动画/过渡压至 0.01ms、`cf-raise`/`cf-slip` 位移清零；framer 入场用 `useReducedMotion()` 直通终态。

## 2. 组件级交互（`components/ui.tsx`）

### 2.1 Button / IconButton / Chip — 触觉按压

- 悬停：底色/描边/文字色 120ms 过渡（显式属性列表 `color,background-color,border-color,box-shadow,transform`）。
- **按压：`active:scale(0.96)`**——业界手感校准值（<0.95 会显得夸张），主按钮、图标钮、胶囊筛选共用同一手感；配合墨锭按钮的内高光，像按下一枚实体印章。
- 加载：`loading` 态保留原按钮文字 + 内嵌 Spinner（规范要求"转圈不换字"），按钮禁用防重复提交。
- 禁用：45% 透明 + `pointer-events-none`，悬停不再变色。

### 2.2 Switch — 合成器滑块

- 滑块位移由 `left: 0→18px` 改为 **`transform: translateX(14px)`**（原实现逐帧触发布局重算；现走合成器，低电量模式也不掉帧）。
- 时长从 120ms 提到 `--motion-base` 180ms——开关是"拨动"语义，需要一点重量感；轨道颜色同步 120ms 过渡。

### 2.3 ScoreBar / 进度条 — transform 揭示

- 基准评分条与动画工作台进度条统一改为 `scaleX(progress)` + `origin-left`，替换原 `width: n%` 内联动画。视觉完全一致，渲染路径从"逐帧 layout"变为"逐帧 composite"。
- ScoreRing（SVG 环）保持 `stroke-dashoffset` 一次性揭示——SVG 标准做法，仅在数据到达时运行一次。

### 2.4 输入族（Input / Textarea / Select）

- 过渡只声明 `border-color, box-shadow`：聚焦时墨色描边 + 3px 暖色柔环同时浮现，`focus-within` 保证点击文字即获得整框反馈。
- 新增统一**墨色插字符**（`caret-color: primary`）——光标也是设计的一部分。
- 移动端（粗指针环境）输入字号强制 ≥16px，杜绝 iOS Safari 聚焦自动放大。

### 2.5 Tabs / Segmented / 底部导航 — 状态必须"看得见 + 读得到"

- Tabs：激活下划线用 framer `layoutId` 在标签间平滑滑移（180ms 标准缓动）；`aria-selected` 同步。
- 移动端底部导航：激活项新增**顶部墨色短条**淡入——颜色（primary 文字）+ 形状（指示条）双线索，不再仅靠颜色传达。

## 3. 页面级交互

### 3.1 路由过渡

- 路由切换整页 `page-enter`：淡入 + 8px 上移（280ms 标准缓动）；动画结束后 transform 归零，不残留包含块影响 fixed 子元素。query 变化不重放。

### 3.2 悬停语义

- 交互卡（`Card interactive`）：`cf-raise` 悬停微抬 1px + e3 柔影，"拈起纸片"的物理隐喻。
- 列表行：底色变 `surface-2/60`（60ms 内感知），行动箭头 `translate-x 2px` 引导点击；无缩放无弹跳——高频区域零编排。
- 灵感签（工作台）：悬停回正（手作纸签从微倾摆正）+ 描边墨化；按压缩放 0.97。

### 3.3 加载反馈（骨架屏同构原则）

| 场景 | 之前 | 现在 |
| --- | --- | --- |
| 试玩舞台 · 人物挑选 | 一行灰字"读取近期生成记录…" | 与最终网格同构的骨架卡（2/4/6 列自适应） |
| 试玩舞台 · 动作画廊 | 一行灰字"渲染动作预览…" | 4 条 58px 骨架行（同卡片高度） |
| 发布展示间 · 角色列表 | 一行灰字 | 图块 + 双行文本的同构骨架行 |
| 工作台 · 基准读数 | （已有同构骨架，保留） | 不变 |

骨架屏形状 = 最终内容形状，加载完成零跳动（CLS ≈ 0）。

### 3.4 空态 = 行动邀请（no dead ends）

| 场景 | 之前 | 现在 |
| --- | --- | --- |
| 试玩区未选人 | 空画布 + 一行"← 先在下方选择一个试玩人物" | 纸雾覆盖层 + 品牌空态（斜纹图章 + 《选一位试玩人物》+ 主按钮「打开人物挑选」） |
| 动作画廊未选人 | 一行灰字 + 大留白 | 居中《动作画廊待命》空态，说明下一步 |
| 挑选器无记录 | 一行灰字 | EmptyState + 主按钮《去工作台生成》 |
| 展示间无角色 | 一行灰字 | EmptyState + 主按钮《去工作台生成》 |

所有空态遵循同一构图：斜纹"未凿"圆角图标章（ember 菱形角标）→ 标题 → 一句说明 → 一个主按钮。

### 3.5 Toast 通知

- 右下角堆叠，入场 180ms（淡入 + 14px 上滑 + 0.97 缩放），退出 120ms 右滑淡出；`role="status"`（隐式 `aria-live: polite`），点击即关。语义色左条为静态冗余线索。

## 4. 可访问性地板（全站生效）

- **焦点**：全局 `:focus-visible` 双环（2px 纸底 + 2px 墨 45%），键盘导航可见、鼠标点击不可见；"跳到主内容"链接常备。
- **命中区**：移动端标签 ≥44px；桌面紧凑控件 ≥32px 且互不重叠。
- **触屏**：`touch-action: manipulation`（禁双击缩放）、`-webkit-tap-highlight-color` 透明（高亮由组件悬停态接管）。
- **对比度**：正文 ≥4.5:1；小号 ember 文字一律用加深档 `ember-ink`（本轮将试玩舞台 Q 版提示从硬编码 amber-700 收敛至令牌）。
- **元数据**：`index.html` 补 `theme-color`（纸色）与 `description`；`color-scheme: light` 声明保持。
