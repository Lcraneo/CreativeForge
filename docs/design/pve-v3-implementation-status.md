# PVE V3 实施状态

## 已接入运行时

- 扫掠弹丸碰撞、按路径选择最近目标、限制攻击当前遭遇战敌人。
- 四种行为分别使用扑击、冲锋、锁定弹丸、震地；技能包含前摇、有效窗口与后摇。
- Boss 半血切换第二阶段，循环弹丸、震地、冲锋。
- 键盘 L / 触控闪避：持续 0.22 秒、无敌 0.18 秒、冷却 1.6 秒，按住不重复触发。
- W / S 与触控按钮上下斜向瞄准，保持单次发射。
- 浮台进入渲染与单向落地碰撞，生成器在普通战区产出低浮台和间歇喷口；喷口有 0.8 秒预警，桥面提供安全路径。
- 遭遇战结构校验覆盖重复 ID、重复或遗漏敌人、Boss 顺序。
- 守卫面对高处玩家使用带前摇的定向弹丸，避免平台下无限震地。
- 修复侧视源图读取回退正面图的契约错误；有侧视源图的敌人生成、预打包与试玩读取使用一致视角；旧版正面素材明确提示未达标。
- 敌人工坊提供 idle/walk/attack 单动作重建入口，保留模型和其他动作；限制重复任务、按动作记录视角、完成后刷新试玩资源。
- 场景编译器固定产出开放场、双层平台、危险走廊、Boss 掩体四种模板；模板边界、平台可达性、喷口安全桥面和掩体尺寸进入自动校验。
- 追击/冲锋敌人可跳上低浮台追击玩家；守卫用带前摇弹丸覆盖高台；Boss 掩体会真实拦截双方弹道。
- 六动作运行时槽位为 idle/walk/windup/attack/hurt/death；三个自定义动作身份自动映射，缺失素材使用程序化回退。
- 结算评级、受伤/防御/命中率统计与本地最佳时间已接入；不同难度和关卡长度的估算时长、弹幕预算与最低前摇进入后端验证结果。
- 1440×900 与 390×844 响应式布局已实测；移动端八个触控动作均在战斗画布内完整可达。

## 尚未达到完整 V3 验收

- 四类场地和简化敌人导航已完成代码与自动验证；仍需人工确认不同尺寸和真实角色素材下的操作手感。
- 六动作代码契约与回退已完成；真实侧视 `windup/hurt/death` 模型资产由后续执行人按 `pve-v3-model-generation-handoff.md` 生成和验收。
- 90–160 秒目标时长、弹幕预算与最低 0.45 秒前摇已有自动校验；弹幕安全区仍需使用最终模型做人工体验验收。
- 评级、最佳记录和双尺寸布局已经实现并检查；使用最终六动作模型的桌面/移动端完整通关录像与手感结论由模型执行人补齐。
- 生产构建、类型检查、相关 lint 均通过；前端完整测试 155 项通过，后端 PVE/场景相关测试 18 项通过。

## 测试重点

纯运行时测试覆盖弹丸穿透、前摇期间无伤害、锁定瞄准、近战防御、Boss 阶段与跳跃躲震地、闪避冷却/无敌、浮台落地和斜向射击。自动测试不能替代实机难度与操作手感验收。
