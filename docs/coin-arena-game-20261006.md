# Coin Arena · 古堡金币竞技场：用 CreativeForge 管线做的完整小游戏

日期：2026-10-06。验证「项目生成的资产能直接做游戏」的端到端示范：
主角 / 敌人 / 背景全部由 CreativeForge 管线生成，同一风格，纯 HTML5
零依赖，浏览器直接玩。

## 玩法

- 访问：`http://127.0.0.1:8600/game/`（后端已挂 /game 静态路由），或
  直接双击 `games/coin-arena/index.html`
- 操作：←→ / A D 移动（Shift 奔跑）· 空格 / J 攻击 · R 重开
- 规则：金币 +10，击败小恶魔 +50，接触掉心（3 心），无尽波次递增

## 关键技术：AI 掩膜投射抠像（tools/build_sprites.py）

i2v 帧自带背景（街道/渐变底），逐帧颜色泛洪不可行——主角米白上衣、
敌人银发与背景同色系，颜色键必吃进主体（三种经典方案实测失败）。
最终方案与项目 `_stabilize_background` 同源：

1. 每资产一次 AI 白底化（ImageEditProvider + SEGMENT_PROMPT）→
   `_flood_subject` 主体掩膜 + `_absorb_enclosed_background` 吸收
   臂弯/腿间封闭白洞；
2. i2v 摄像机锁定（构图子句保证），帧 = 源图主体 bbox（外扩 6% 补
   方形）区域——掩膜按同一裁剪框投射到每帧；
3. 主角走紧轮廓硬裁（膨胀 6px，i2v 白底带暗角时软清理清不干净）；
   敌人白底干净走软掩膜 + 边界连通白底清理 + 羽化。

产物：32 帧 @12fps 透明底横排图集（主角帧宽 110 / 敌人 167），
`assets/manifest.json` 记录帧数与帧宽。

## 踩过的坑（勿重蹈）

1. **ImageEditProvider 的白底化产物找错文件**：SEGMENT_PROMPT 编辑的
   产物目录里有多个资产的输出（敌人任务管线自己也做白底化），凭时间戳
   猜文件名会把恶魔白底当成主角的——白底图必须目检或用
   `_arena_white_sources.json` 缓存固化（build_sprites 现在会存）。
2. **i2v 原始帧自带黑色衬边（pillarbox）**：白底区不与帧角落连通，
   一切以角落为参考色的泛洪都会失效——先按列扫描裁掉黑边再抠。
3. **逐帧颜色泛洪对同色系主体不可行**（三次实测失败），直接上 AI 掩膜。
4. **背景修补用镜像贴片会留接缝**——构图性避让（裁切）比修补稳。

## 游戏本体

- `index.html + game.js`：原生 Canvas，固定时间步进 60fps，零依赖；
  sprite sheet 按帧切片 + 负 x 镜像转向；攻击命中帧窗口判定；敌人
  追踪 AI + 受击硬直/击退/红闪；金币椭圆旋转；WebAudio 合成音效；
  固定键位防页面滚动。
- `tools/build_sprites.py`：资产构建管线（上文）；`tools/key_frames.py`
  为色键方案的留档（被掩膜方案取代）。

## 验证

- 浏览器实测（内置浏览器键盘事件注入）：开始遮罩 → 移动转向 → 攻击
  命中（敌人血条出现）→ 金币拾取计分（分数 10→30→40 连续增长）→
  接触掉血无敌闪烁 → 双侧波次刷怪，全部通过。
- 素材链：敌人 t2i qa=pass；4+2 条 i2v 全部 qa=pass；一致性：敌人暗红
  系为敌意设计偏移，画风同为动漫平涂。
