# Studio 前端与服务协作：第一批 P0 改造

日期：2026-10-05。范围为首批可信度、可读性和等待反馈优化，不代表整份增强路线图已完成。

## 已落地

- 导出结果、角色包、进行中状态和失败原因按资产 ID、目标引擎和操作类型隔离。同一操作在等待期间拒绝重复提交；切换资产后的迟到响应保留在原资产上下文。
- 导出页显示资源打包与包结构校验，成功后不再保持“Package 运行中”。区分内部结构校验与编辑器实际导入验证；尚未增加原生引擎工程适配器。
- 工作台移除固定路径的趋势线、固定纠偏比例和固定质量宣传数字，展示真实基准报告的样本数、时间和测量值。加载失败可重试，不影响创建资产。
- 辅助文字 ink-3 / ink-4 调整为 #5f594f / #625c52；在 canvas、surface-1、surface-2、surface-3 上计算对比度最低分别为 4.82:1 / 4.60:1。其他语义颜色不在此结果内。
- 基准报告缓存 600 秒，并原子持久化到 studio/backend/data/benchmark-report.json；启动时根据评测、引擎与协议源码指纹失效旧报告。同一缓存实例合并并发重算；失败不覆盖已有成功报告。只适用于当前单进程部署。
- 基准中心提供手动重新评测，保留测量时间；失败时保留旧报告并提示。首次无缓存、缓存过期和手动刷新仍运行真实评测，本批未实现后台刷新。
- 任务事件立即应用，不再为动画每条延迟 170ms。WebSocket 失败后从已接收事件游标继续读取同一追加日志；轮询串行并退避，卸载时取消请求，终态停止请求。
- fail 与未知结束状态不再误报成功。导出接口由页面负责错误提示，避免 API 层重复 toast。
