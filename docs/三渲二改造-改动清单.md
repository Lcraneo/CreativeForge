### 关键改动点
- **着色逻辑提炼自 Windup**（重写不拷贝）：硬边色阶（参考项目 NearestFilter gradientMap → 本实现 shader 内 `floor` 量化，少一次纹理采样）；材质重建继承源材质 side/map/color（保留参考项目的"丢 doubleSided 满身白斑"教训）
- **可调参数**（全走 uniform，改参数不重编译、不重建材质）：描边宽度 / 颜色、明暗色阶数量（2–8）、阴影阈值、高光范围、边缘光强度
- **描边**：inverted hull（法线外扩 + BackSide），单 pass、无后处理，帧率代价接近一次普通绘制
- **帧率**：单 pass toon + 单 pass outline，无后处理链；面板内置 FPS 探针实时显示
