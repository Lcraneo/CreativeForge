# Studio 前端 P1：资产上下文深链

日期：2026-10-05。

## 改动

- `useAssetLoader()` 读取路由查询参数 `?asset=<id>`，页面刷新或复制链接后按指定 ID 加载资产。
- 指定资产加载时清空旧资产，避免页面在请求期间短暂显示另一角色；指定 ID 失效时显示明确错误状态，不静默回退到最新资产。
- 新增 `assetHref()`，历史记录、智能体结果、资产检查器、批量产出、版本中心、动画人物选择和生成结果的跨页入口都会携带资产 ID。
- 导出页此前已经按资产和引擎隔离，本批将其他生产页面接入同一 URL 语义。

## 用户价值

用户从历史记录打开角色后，进入设计、动画或导出页面时仍操作同一资产；分享深链或刷新页面不会因为“最新资产”变化而串角色。后端重启后的历史资产也继续通过指定 ID加载。

## 边界

试玩舞台和展示间保留各自的显式人物选择器，但现在会读取 URL 资产作为初始选择并在用户切换时更新 URL；不会自动跟随全局最新资产。

## 验证

- 新增 `assetHref` 单测，覆盖 URL 编码、已有查询参数和空 ID。
- 前端 typecheck、Vitest、构建需在本批全部通过；浏览器深链验收需等本地服务和审批恢复后执行。
