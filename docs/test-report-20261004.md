## 4. 缺陷清单

### 4.1 本次测试发现并已修复（随修随验，均已推送）

| 编号 | 级别 | 缺陷 | 根因 | 修复提交 |
|---|---|---|---|---|
| D-1 | P1 | 单资产导出对历史资产全 404 | 用内存 store 未走历史兜底 | 243a4ba |
| D-2 | P1 | 三引擎导出包名相同互相覆盖 | 包名无引擎/时间戳 | 243a4ba |
| D-3 | P2 | 角色包 view_front 永远缺失 | front 本就复用原画未派生 | 243a4ba（回退原画） |
| D-4 | P2 | 打开工作台人物自发动作/变形 | 骨架预览帧未经交互自动渲染 + 恢复视频 autoPlay | 76ee394 / b2abb1d |
| D-5 | P2 | 2MB 非法图片返回 500 | PIL UnidentifiedImageError 继承 OSError，路由只捕 ValueError | 本报告（400 归一） |
| D-6 | P3 | 未知 /api/* 返回 SPA 200 HTML | SPA 兜底吞掉 API 404 | 本报告（/api 404 JSON） |
| D-7 | P3 | 恢复逻辑 no-useless-assignment（eslint 唯一 error） | catch 内冗余赋值 | 243a4ba |

### 4.2 复测后排除的"疑似缺陷"（脚本口径问题）

- GET /api/tasks 返回 `{"tasks":[...]}` 对象而非裸列表（前端按此消费，设计如此）
- /api/settings/model 的 `key_hint: "sk-****IPyQ"` 为**脱敏提示**，非明文泄露（api_key 字段本身不回显）
- 动画接口空 body 会落在"最近资产"上生成——历史兜底的同源化设计，前端总是显式传参（建议在接口文档标注）
- /api/prompt/enhance 字段为 `goal` 而非 `text`（文档口径）

### 4.3 未修复（改进建议）

| 编号 | 级别 | 问题 | 建议 |
|---|---|---|---|
| D-8 | P2 | GET /api/benchmark 每次同步重算 13s，基准中心页每次访问卡 13 秒 | 结果落盘 + TTL 缓存（如 10min），或后台定时刷新 |
| D-9 | P3 | GImport 导出为引擎无关 JSON 清单，三引擎 manifest 同文 | 若需演示引擎差异，产出原生工程文件（.unitypackage/.tscn）为独立增强项 |
